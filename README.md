# 弹墨 · 深渊回响

零依赖的水墨风弹珠 Roguelike。纯 Canvas 2D 渲染，音效与配乐全部由 Web Audio 程序化合成 —— 没有一张图片、一个采样，也没有任何第三方库。

## 怎么玩

按住画面拖动瞄准，松开发射。珠子在深渊里反复弹跳、撞碎墨点；每层有「碎墨」配额，配额未满就用完了砚台里的珠子，这一层就过不去。

- 26 种墨诀（局内构筑）、6 种朱印、5 种角色、5 项永久解锁
- 配额按你实际的单珠碎墨量自适应推导，所以不会出现「词条再好也凑不齐目标」的死局，压力落在评分与推进速度上
- 支持局内暂停存档；中途弃墨而退也会照常结算墨髓

## 运行

直接双击 `PC/index.html`（或 `Android/index.html`）即可开玩，不需要构建，也不需要起服务器。

## PC 与 Android 是两个独立版本

两端的适配需求不同，因此分开维护，改动不默认互相同步。

| | PC | Android |
| --- | --- | --- |
| 战场尺寸 | 900 × 660 | 1173 × 660（16:9） |
| 开局墨点上限 | 145 | 220 |
| 右下角按钮 | 30 px | 36 px |
| 屏幕适配 | 桌面居中缩放 | 锁定横屏、刘海安全区、沉浸式 |
| 玩法 / 音乐 / 音效 | 一致 | 一致 |

`Android/弹墨.apk` 是已签名的 release 安装包（versionName 1.3、versionCode 4，minSdk 23 / targetSdk 35），已关闭 WebView 调试与应用调试。使用原签名覆盖安装即可升级并保留本地进度；旧版本 APK 的调试设置不会因仓库更新而自动改变。

## 音乐

三套音景随关卡深度改变强度，全部程序化生成：

- **静水** —— 竹笛独奏，连奏不断线
- **行墨** —— 大提琴独奏，长弓
- **深渊** —— 电吉他 riff 加鼓，越深越重

旋律、鼓组、和声都由 pattern 表驱动而非随机数，因此每一遍的律动完全一致。
